# First post

This site is built by *sitegen*, a static site generator written in **pith**.

## What it does

- parses front matter
- renders a small markdown subset
- emits an index, tag pages, and a [json feed](/feed.json)

```
pith build tools/sitegen/sitegen.pith
```
