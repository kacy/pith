notes - keep short notes

Usage: notes [options] <command>

Options:
  -f, --file <value> - notes file (default: notes.txt)

Commands:
  add - add a note
  list - list notes

notes add buy milk: add "buy milk" to notes.txt
notes add --file work.txt --tag urgent ship the release: add "ship the release" tagged urgent to work.txt
notes -f home.txt list -a -n 3: list up to 3 notes from home.txt, archived too
notes remove 1: error: unknown command: remove
notes add: error: missing positional argument: text
