thumbs - make thumbnails of the images in a directory

Usage: thumbs [options] <dir>

Arguments:
  dir - directory of images

Options:
  -n, --dry-run - list what would be written
  -s, --size <value> - longest edge in pixels (default: 256)
  -f, --format <value> - output format (default: webp)

would write 128px webp thumbnails for photos/
