# key|params|result|evidence|note
#
# what each runtime function does with the reference counts of its arguments
# and its result. the count checker reads this instead of trusting the
# emitter, which is the thing it checks. build.rs refuses a key from
# runtime_functions.txt without exactly one row here.
#
# params, one token per parameter:
#   -   not a counted value (an int, a float, a length, a tag, a file handle)
#   b   borrowed: read during the call; the caller's count is left alone. a
#       callee that keeps the value takes a count of its own.
#   c   consumed: the callee takes over the caller's count
#
# result:
#   -          void, or not a counted value
#   own        the caller gets a count it must give up
#   borrow:N   valid only while argument N lives and is unchanged
#   pair:...   the function returns the (flag, payload) register pair, and
#              the rest of the token describes the payload
#
# retain functions are `b` here: they add a count, which the checker knows by
# name. evidence is the line of the code or doc comment that decides a row.
# each row comes from the runtime source, not from how the emitter calls it.
